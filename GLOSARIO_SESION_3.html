Arquitectura Cognitiva y Agentes Bloque 1

Analizamos cómo los modelos evolucionan desde sistemas de consulta hacia agentes que resuelven problemas complejos de negocio de forma autónoma.

01 IA Pasiva vs. IA Activa
Paradigma
La IA Pasiva se limita a generar respuestas basadas en información recuperada (RAG). La IA Activa utiliza el razonamiento para decidir qué herramientas necesita y ejecutar acciones en sistemas externos.
Evolución de capacidades: De informar a ejecutar.
💡
Caso de uso: Mientras que una IA Pasiva te informa el nivel de stock, una IA Activa identifica el faltante y genera una orden de compra para que vos la apruebes.
🎯 Enfoque PM / Estrategia
Tu planificación ya no se centra únicamente en la visualización de datos, sino en las herramientas y permisos que el agente requiere para operar con autonomía.
02 Loop ReAct
Proceso
Marco de razonamiento donde el agente itera en tres pasos: Pensar (Planificar), Actuar (Usar una herramienta) y Observar (Analizar el resultado para determinar los siguientes pasos).
El motor de razonamiento: Pensar -> Hacer -> Evaluar.
💡
Analogía Profesional: Es el flujo de trabajo de un consultor estratégico. Primero analizás el problema, luego ejecutás una acción y finalmente evaluás los resultados para decidir cómo continuar.
03 Patrón Orchestrator-Workers
Arquitectura
Arquitectura multi-agente donde un Orquestador central descompone una tarea compleja y la distribuye entre varios Workers especializados, consolidando luego la solución final.
Especialización: Cada Worker es experto en una subtarea específica.
🎯 Enfoque PM / Estrategia
Esta estructura reduce significativamente las alucinaciones del modelo. Al gestionar un equipo de agentes especializados, lográs mayor precisión y facilidad en el testeo de cada componente.

Integración y Gobernanza Bloque 2

04 Tool Calling
Integración
Capacidad del LLM de solicitar la ejecución de una función externa. La IA genera un JSON estructurado con los parámetros necesarios para que tu sistema ejecute la acción.
Tool Calling: El puente entre el lenguaje natural y el código.
💡
Ejemplo: Si el agente necesita consultar una base de datos, no inventa la respuesta; emite una solicitud técnica para que tu backend le devuelva la información real.
05 Human-in-the-loop (HITL)
Gobernanza
Punto de control donde el agente detiene su proceso y solicita autorización manual antes de realizar una acción crítica, irreversible o de alto impacto.
Garantía de seguridad: El factor humano como validador final.
🎯 Enfoque PM / Estrategia
Es tu principal mecanismo de mitigación de riesgos. Definir qué acciones requieren aprobación (ej: transacciones monetarias elevadas) es una decisión estratégica del Product Manager.
06 Validación Estructurada
Seguridad
Implementación de esquemas técnicos (Pydantic / JSON Schema) para garantizar que los datos generados por la IA cumplan estrictamente con el formato requerido por tus sistemas centrales.
Integridad de datos: Protegiendo la arquitectura corporativa.
