Sesión 3: IA Activa & Agentes

Más allá del simple chat corporativo

Hoy cruzamos la línea: del bot que solo contesta (RAG Pasivo) al sistema que razona, decide y opera de forma autónoma.

  • Conceptos Clave: Loop ReAct, Tool Calling.
  • Arquitectura: Orchestrator-Workers.
  • Gobernanza: Pydantic, HITL, API Gateways.

El Bucle del Razonamiento

Cómo la IA decide sus próximos pasos

Usamos el Loop ReAct para que el agente piense antes de mandarse una macana.

  • Thought: El modelo verbaliza su plan de acción.
  • Action: Invoca una API usando Tool Calling.
  • Observation: Lee el resultado y vuelve a razonar.

Como PM, podés auditar estos pasos para entender la lógica del bot.

Escalando con Orquestación

Divide y vencerás en el stack técnico

Implementamos el patrón Orchestrator-Workers para maximizar la precisión:

  • Orquestador: El cerebro que planifica y reparte el laburo.
  • Workers: Micro-agentes expertos (SQL, PDFs, Web).

Esto reduce alucinaciones y te permite tener un control total sobre cada micro-tarea.

Gobernanza & Blindaje

Tu responsabilidad estratégica como líder

No dejamos a la IA suelta. Ponemos barreras técnicas rígidas:

  • Pydantic: Validación estricta de cada dato que sale de la IA.
  • API Gateways: Aislamiento para que la IA no rompa nada.
  • HITL: Puntos de aprobación humana obligatoria.

Eficiencia & Observabilidad

Operando IA a nivel Enterprise

Para que el producto sea viable y rentable necesitamos:

  • KV Cache: Reducción de latencia y hasta 80% de ahorro.
  • Langfuse: Monitoreo en tiempo real de trazas y costos.
  • Max Iterations: Cortafuegos contra bucles infinitos.
